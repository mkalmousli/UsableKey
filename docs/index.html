  1. Download the APK from the latest release and install it.

  3. Tap Switch to UsableKey, then choose your languages.

FAQ

Which Android versions does UsableKey support?

UsableKey is built with minSdkVersion 3, which is Android 1.5 Cupcake, and targets Android 14. It is developed and tested on a recent device; very old versions are untested, so please report any problems.

How big is UsableKey?

The whole APK, including 13 dictionaries and 60+ layouts, is under 1 MB. It uses no third-party libraries.

Does UsableKey send my typing anywhere?

No. It does not request the INTERNET permission, so it cannot send data off your device. Suggestions and the clipboard history are stored locally.

Is UsableKey free?

Yes. It is open source under the MIT license, with no ads and no accounts.

How do I install it?

Download the APK from the latest GitHub release, install it, then open the app and follow Enable keyboard and Switch to UsableKey.
