⌨️ UsableKey

A tiny, fast, private Android keyboard. 60+ layouts, offline suggestions, emoji and clipboard history in about 800 KB.

Download APK View on GitHub

Features

🌍

60+ layouts

QWERTY, QWERTZ, AZERTY, Dvorak, Colemak, Cyrillic, Arabic, Hebrew, Thai, Devanagari and more, generated from Unicode CLDR.

💡

Offline suggestions

Auto-correct and word prediction for 13 languages with fuzzy matching. Nothing leaves your phone.

😀

Emoji

Categories, recents and flags.

📋

Clipboard history

Text and images, with an image shelf for sending pictures into apps.

🛠️

Editing tools

Arrows, select, cut/copy/paste, undo/redo, Ctrl/Alt/Fn.

🎨

Themes

Dark, light, AMOLED and blue, with adjustable key height.

🔒

Private

No internet permission, no tracking, no accounts.

🪶

Tiny

About 800 KB, no libraries, runs on Android 1.5 and up.

Get started

  1. Download the APK from the latest release and install it.
  2. Open UsableKey and tap Enable keyboard.
  3. Tap Switch to UsableKey, then choose your languages.
